# 截图 OCR 翻译

截图 OCR 页的图片工具栏，在“文字”左侧增加了“翻译”复选按钮。首次启动默认不勾选，默认方向为**英语 → 简体中文**。

1. 点击“翻译”开启，再截图、粘贴或拖入图片。已有识别结果时，开启会立即翻译当前结果。
2. 点击旁边的 **▾**，选择源语言、目标语言和服务。源语言可以选择“自动检测”。也可在截图 OCR 的“设置 → 识别后翻译（联网）”中修改。
3. 结果区域的“译文”页显示当前图片的原文与译文，可复制译文或重新翻译。“记录”页与图片文字叠加层保留 OCR 原文。
4. 开关、语言及服务会通过原有配置系统保存到 `UmiOCR-data/.settings` 的 `ScreenshotOCR` 分组，重启后恢复。关闭翻译时不再发送翻译请求。

图片区域较窄时工具栏分为两行，避免翻译按钮被截图和粘贴按钮遮挡。极窄时隐藏辅助图标，仍可右键图片使用原有操作。

## 免费服务选择

| 服务 | 使用方式 | 自动检测 | 限制 |
| --- | --- | --- | --- |
| Google（默认） | 免 Key 的网页翻译端点 | 支持 | 非官方稳定 API，无可用性保证；部分网络无法直连，可能限流 |
| MyMemory | 公开免费 API，免注册、免 Key | 不支持，需选明确的源语言 | 官方公布匿名使用每日 5000 字符、单请求最多 500 UTF-8 字节；额度以服务实际响应为准 |

默认选用 Google，便于获得通用机器翻译和自动检测能力；MyMemory 可作为网络可用时的备选。翻译质量取决于文本、OCR 质量和语言组合，未做系统准确率评测。没有自动切换服务，文字只发送到用户选择的服务。

实现使用 Python 标准库 `urllib`，无需安装额外翻译库或申请付费 Key。`deep-translator` 等封装库仍依赖上游服务，本次直接适配上述两个接口，兼容项目内置 Python 3.8 环境。

参考：[MyMemory API 参数](https://mymemory.translated.net/doc/spec.php)、[MyMemory 免费额度](https://mymemory.translated.net/doc/usagelimits.php)、[deep-translator 的 Google/MyMemory 适配实现](https://github.com/nidhaloff/deep-translator)。Google 使用 `translate.googleapis.com/translate_a/single` 网页端点，并非 Google Cloud 付费 Translation API。

## 行为和异常处理

- OCR 继续离线运行。只有开启翻译后，识别出的**文字**才会发送到所选在线服务；图片不发送到翻译服务。
- 翻译在后台执行，不阻塞识图界面。新结果、修改配置或关闭开关会使旧请求失效，旧译文不会覆盖新结果。已经发出的网络请求无法撤回。
- 相同文本、服务和语言方向的成功结果会在内存中缓存 10 分钟，最多 128 条；重复识别直接复用，退出后清空。点击“重新翻译”会跳过缓存重新请求。
- Windows 内置 Python 3.8 检查系统代理时，原生 `urllib` 可能因反向 DNS 查询额外等待约 9 秒。翻译请求改用不执行反向 DNS 的代理例外匹配，保留系统代理、HTTPS 证书验证、主机名/端口通配符和 `<local>` 例外；IP 规则匹配 URL 中的 IP，不额外解析主机名。本机对示例短句的首次翻译耗时由约 10 秒降至约 0.85 秒，其他网络下耗时仍取决于连接和服务响应。
- 长文本按句子、空格及 UTF-8 字节限制分段；MyMemory 每段最多 450 字节，Google 每段最多 3500 字节。每次最多 20000 字符，单请求超时最多 12 秒，分段任务在约 60 秒后停止继续请求。
- 超时、断网、限流和额度不足会在译文页提示，可重试或切换服务。失败不覆盖原始 OCR 结果。
- MyMemory 选择“自动检测”时会提示指定语言或切换 Google。
- 译文页显示最近一次识别结果，历史原文仍在“记录”页。

## 运行与验证

Windows 项目目录如已包含运行环境，直接运行根目录的 `Umi-OCR.exe`。仅拉取源码时，按主 README 的[构建说明](../README.md#构建项目)准备运行环境和 OCR 插件。

翻译适配器测试无需 Qt 或联网：

```powershell
python -m unittest discover -s tests -v
```

本地另外验证了内置 Python 3.8 下的 Google 英译中、自动检测日语、MyMemory 英译中，以及 Qt 界面中 RapidOCR 识别图片后显示译文的完整流程。
